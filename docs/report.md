# fNIRS 脑血氧数据分析报告

## 背景

这份数据来自一台 12 通道的 fNIRS（功能性近红外光谱）脑血氧检测设备，采集时间为 2025-12-03。设备通过向头皮发射近红外光，测量光在脑组织中的吸收变化，从而间接反映脑区的血氧浓度变化。

原始数据文件包含 16 个通道（CH0~CH15），共 38,692 个采样点。

## 设备结构

### 探头空间布局

设备贴在前额叶区域，12 个探测通道（CH1~CH12）和 4 个光源（L1~L4）排列如下：

```
CH6   CH5   CH4   CH3   CH2
CH12  [L1]  [L2]  [L3]  [L4]  CH1
CH11  CH10  CH9   CH8   CH7
```

光源在中间一排，探测器分布在上下两排和两端。

### 光源与探测器的对应关系

每个光源发出的光会被周围 4~5 个探测器接收到：

| 光源 | 接收通道 |
|------|---------|
| L1 | CH5, CH6, CH10, CH11, CH12 |
| L2 | CH4, CH5, CH9, CH10 |
| L3 | CH3, CH4, CH8, CH9 |
| L4 | CH1, CH2, CH3, CH7, CH8 |

注意很多通道是共享的——比如 CH5 同时接收 L1 和 L2 的光，CH9 同时接收 L2 和 L3 的光。这是导致信号混叠的根本原因之一。

### 双波长与时分复用

每个光源内含两个灯泡，分别发射 730nm 和 850nm 的近红外光。设备采用时分复用（TDM）策略：4 个光源按顺序轮流发射，每次只亮一个灯泡。一个完整周期约 25 个采样点，包含 8 次发射事件（4 光源 × 2 波长）。

### 特殊通道

| 通道 | 用途 |
|------|------|
| CH0 | 未知（有信号，可能是额外探测器或参考通道） |
| CH13 | 全周期标记信号（幅度极小，约 -0.012） |
| CH14 | 有信号，交替周期为 3（可能是时序参考或额外探测器） |
| CH15 | 切换周期标记信号（幅度极小，约 -0.012） |

CH13 和 CH15 虽然幅度很小，但它们不是"死通道"——它们是设备内部的时序参考信号，标记了发射周期的节拍。

## 发现的问题：双波长信号混叠

### 什么是双波长？

fNIRS 设备使用 730nm 和 850nm 两种波长的近红外光。这两种光对含氧血红蛋白（HbO）和脱氧血红蛋白（HbR）的吸收率不同，通过对比两种波长的信号变化，才能分别计算出 HbO 和 HbR 的浓度——这才是 fNIRS 真正有用的数据。

### 这份数据出了什么问题？

正常情况下，设备应该把两种波长的信号分开记录（比如 CH1_730nm 和 CH1_850nm）。但这台设备的大部分通道把两种波长的信号混在了一起——它们被交替采样后写进了同一个通道。

具体表现：信号在正值和负值之间周期性地来回跳。以 CH14 为例：

```
时间点 0:  -1.6636  ← 波长 B
时间点 1:  -1.6639  ← 波长 B
时间点 2:  +0.4626  ← 波长 A（过渡）
时间点 3:  +1.6400  ← 波长 A
时间点 4:  +1.6406  ← 波长 A
时间点 5:  +0.9603  ← 波长 A（过渡）
时间点 6:  -1.6633  ← 波长 B
...
```

可以看到，信号严格按照"3 个正值、3 个负值"的节奏交替。正值段是一种波长的信号，负值段是另一种波长的信号。

### 16 个通道的分类结果

经过自动检测，16 个通道分为三类：

| 类型 | 通道 | 说明 |
|------|------|------|
| 混叠通道 | CH0, CH2, CH3, CH5, CH6, CH7, CH8, CH9, CH10, CH11, CH12, CH14 | 两种波长信号交替混在一起，交替周期各不相同 |
| 纯净通道 | CH1, CH4 | 信号平稳，没有周期性跳变，只包含单一波长 |
| 死通道 | CH13, CH15 | 信号几乎恒定在 -0.012 附近，标准差仅 0.0015，基本是电路底噪 |

各混叠通道的交替周期（run length）不同，这是因为不同通道接收的光源数量不同：

- 只接收 1 个光源的通道（如 CH12 只收 L1）：交替周期长（12~19），因为一个完整周期里只有该光源的 2 次发射与它有关
- 接收 2 个光源的通道（如 CH9 收 L2+L3）：交替周期短（3~6），因为更多发射事件会影响它
- 接收更多光源的通道（如 CH5 收 L1+L2）：交替周期最短（2~3）

具体数据：

| 通道 | 交替周期 | 含义 |
|------|---------|------|
| CH5 | 2 | 每 2 个采样点切换一次波长 |
| CH7, CH9, CH14 | 3 | 每 3 个采样点切换一次 |
| CH3, CH8, CH10, CH11 | 6 | 每 6 个采样点切换一次 |
| CH12 | 12 | 每 12 个采样点切换一次 |
| CH2 | 13 | 每 13 个采样点切换一次 |
| CH0, CH6 | 19 | 每 19 个采样点切换一次 |

## 解决方案：信号解复用（Demux）

### 原理

既然两种波长的信号是按固定节奏交替出现的，我们就可以反过来把它们拆开：

1. 找到信号正负翻转的边界点
2. 把正值段归为波长 A，负值段归为波长 B
3. 对各自的空缺位置做线性插值，补全成完整的时间序列

这样，一个混叠通道就被拆成了两个独立的信号：`CH12_A`（波长 A）和 `CH12_B`（波长 B）。

### 分离效果

以几个代表性通道为例，分离前后信号的"跳变程度"（相邻采样点差值的标准差）对比：

| 通道 | 分离前 | 波长 A | 波长 B | 平滑度提升 |
|------|--------|--------|--------|-----------|
| CH12 | 0.8956 | 0.0933 | 0.1029 | ~9x |
| CH14 | 1.7749 | 0.2298 | 0.2313 | ~8x |
| CH8  | 0.7683 | 0.2522 | 0.1463 | 3~5x |

分离后的信号平滑了 3 到 10 倍，说明解复用是有效的。

## 分离后的数据

处理后输出 `separated_signals.csv`，包含 26 列：

- 12 个混叠通道 × 2 = 24 列（如 `CH2_A`, `CH2_B`）
- 2 个纯净通道保持原样（`CH1`, `CH4`）
- 2 个死通道（CH13, CH15）被丢弃

## 待确认事项

1. **发射时序**：4 个光源的具体发射顺序（初步推测可能是 L1A→L1B→L2A→L2B→L4B→L4A→L3B→L3A，但需要确认）。确认后可以更精确地做信号分离，区分"来自哪个光源的哪个波长"。

2. **波长对应关系**：分离出的正值段（波长 A）和负值段（波长 B）具体对应 730nm 还是 850nm？确认后才能计算 HbO/HbR 浓度。

3. **采样率**：原始数据没有时间戳列，需要确认采样率才能标注时间轴和做频域分析。

4. **CH0 和 CH14 的用途**：这两个通道有信号但不在 12 通道布局内，需要确认是额外探测器还是参考通道。

## 使用方法

```bash
# 处理默认数据文件（完整流程 + 图表）
python -m src.main

# 处理指定文件
python -m src.main path/to/data.xlsx

# 指定输出目录
python -m src.main data.xlsx -o ./results

# 只做数据处理，跳过图表生成（更快）
python -m src.main data.xlsx --no-figures
```
