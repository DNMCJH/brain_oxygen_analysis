# Brain Oxygen Analysis

This project focuses on analyzing brain oxygenation signals based on real-world sensor data.

## Background
The dataset comes from a brain oxygen monitoring experiment, containing time-series signals collected from sensors.

## Goal
- Perform data preprocessing and exploratory analysis
- Build baseline machine learning / deep learning models
- Establish an end-to-end applied ML workflow

## Structure
- `data/`: data files
- `notebooks/`: exploratory analysis
- `src/`: core source code
